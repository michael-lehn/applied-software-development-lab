# Applied Software Development Lab

English edition of the teaching materials for the undergraduate course
*Praktikum Anwendungsorientierte Softwareentwicklung* (Applied Software
Development Lab) at Ulm University, Germany.

The materials are being prepared from the German original in
[michael-lehn/avr-bare-metal](https://github.com/michael-lehn/avr-bare-metal).
